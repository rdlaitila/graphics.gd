# bundled/libgodot/

C sources compiled into `libgodot.<goos>.<goarch>.a` by the gdnext
libgodot builder.

## Files

Every `musl_*` file is compiled only when building a musl libgodot
target (`LibC == "musl"`); glibc builds pull none of them in. The
prefix makes that provenance explicit at a glance.

- `musl_dlopen.c` / `musl_foreign_tramp.S` — snapshot copies of
  `startup/internal/dlopen/{dlopen.c,foreign_tramp.S}`. Source of
  truth for the Cosmopolitan-style in-process ELF loader lives there;
  these copies exist because `go:embed` cannot walk out of its own
  directory, and the shim needs to ship inside the reproducible
  libgodot artefact so consumers do not have to re-compile it via cgo.
- `musl_helper.c` — the tiny glibc helper program that records
  glibc's `dlopen`/`dlsym`/etc pointers and longjmps back into the
  musl parent. Extracted from what used to be a `HELPER` string
  macro in upstream `dlopen.c`; compiled at libgodot-build time as a
  real ELF and embedded as a byte array into `libdlopen.a` (see
  `compileMuslShim` in `cmd/gdnext/internal/builder/libgodot.go`).
- `musl_execinfo.h` / `musl_execinfo.c` — no-op `<execinfo.h>` shim
  so Godot's `crash_handler_linuxbsd.cpp` compiles when zig-cc is
  targeting musl. `execinfo.h` is planted under a scratch include
  dir prepended to `CPATH`; the `.c` provides silent
  `backtrace{,_symbols,_symbols_fd}` stubs merged into
  `libdlopen.a`.
- `*.sh.tmpl` — zig-forwarder shim scripts planted under
  `$GDPATH/libgodot-shim/<goos>-<goarch>-<libc>/` and prepended to
  PATH so SCons picks up our zig toolchain as cc/c++/ar/ranlib.

## gdnext-only patches on top of the upstream snapshot

1. `SHIM_LOG` / `SHIM_LOG_ERRNO` macros gated on `GDNEXT_SHIM_DEBUG=1`,
   wired at every silent-return path in `foreign_compile`, `foreign_setup`,
   `elf_load`, `elf_exec`, and `dlopen`. When a shim boot fails, run the
   resulting binary with `GDNEXT_SHIM_DEBUG=1 ./yourprog` to surface why.
2. Bazzite/Fedora Atomic MDWE fix in `elf_map`: file-backed pages are
   mapped directly with their final ELF protection (no RW→RX transition
   via mprotect) so systemd's `MemoryDenyWriteExecute=yes` /
   `PR_MDWE_REFUSE_EXEC_GAIN` doesn't reject the interpreter load with
   EACCES.
3. `foreign_compile` uses `memfd_create` + `/proc/self/fd/N` for
   `elf_exec` instead of shelling out to `cc` on a `.c` file cached on
   disk. Requires the pre-compiled helper binary to be embedded into
   `libdlopen.a` as `embedded_helper_bytes[]` (auto-generated by the
   gdnext builder from `musl_helper.c`). Zero runtime dependencies on
   the end user's toolchain; no filesystem cache to invalidate.

## Re-sync when upstream changes

    cp startup/internal/dlopen/dlopen.c \
       cmd/gdnext/internal/builder/bundled/libgodot/musl_dlopen.c
    cp startup/internal/dlopen/foreign_tramp.S \
       cmd/gdnext/internal/builder/bundled/libgodot/musl_foreign_tramp.S

Then re-apply the three patches above (search git history for
`SHIM_LOG`, `PR_MDWE_REFUSE_EXEC_GAIN`, and `memfd_create` to see the
exact hunks). If the upstream `HELPER` string macro drifts, port the
changes into `musl_helper.c` here and drop the macro from our copy
again.
